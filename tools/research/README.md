# tools/research —— 一次性调研脚本

这里放的是**一次性**的逆向、抓取与调试脚本，不是构建链路的一部分。

## 与 `scripts/` 的区别

| | `scripts/` | `tools/research/`（本目录） |
|---|---|---|
| 用途 | 构建、发布、部署、版本与文档门禁 | 一次性调研、竞品逆向、截图分析、临时排障 |
| 是否进 CI | 是（`set-version.ps1 -Check`、`check-docs.ps1`、`check-core-portable.ps1`、`build-installer.ps1`） | 否 |
| 干净克隆下可运行 | 是 | **多数不能**，见下 |
| 维护承诺 | 有：坏了要修 | **无**：坏了直接删 |

分出这个目录的原因：`scripts/` 曾有 52 个文件，其中 33 个是这类脚本，
23 个引用了被 gitignore 的 `dist/staging`、15 个依赖未声明的 `androguard`。
它们混在构建脚本里，让「哪些脚本是活的」无法判断。

## 运行前提（多数脚本不满足）

- **输入数据不在版本库**：23 个脚本读 `dist/staging/`（已 gitignore）或本机
  APK/截图；没有这些输入就跑不起来，这是预期行为，不是 bug。
- **依赖未打包**：Python 依赖见 `requirements.txt`，需自行 `pip install -r`。
  Android 逆向类还需本机 `adb` 与目标 APK。
- **部分脚本硬编码了作者本机路径**（如 `emu-tap.py`），换机器需自行修改。

## 处置原则

- 需要再跑一次 → 先读脚本头部注释确认输入前提，缺什么补什么。
- 跑不起来且短期不需要 → **直接删**，不要花时间修。git 历史留着可追溯。
- 某个脚本变成了长期依赖 → 把它移回 `scripts/`，补齐可重现性（去掉硬编码
  路径、声明依赖），并纳入 CI 或文档。
