# M2 验收：剪贴板历史与面板

前置：`cargo build -p shurufa-host`，然后运行 `scripts/start-host.cmd`
（或手动 `target\debug\shurufa-host.exe run`）。

## 1. 采集入库

1. 在任意应用复制几段文本、在资源管理器复制文件、截图工具复制一张图
2. `shurufa-host list` 应看到对应条目（文本/文件/图片），来源列显示进程名
3. 连续复制同一段文本，`list` 中只有一条且时间刷新（哈希去重）
4. 在 KeePass/1Password 等密码管理器里复制，`list` 不应出现（敏感来源过滤）

## 2. CLI 管理

```bash
target/debug/shurufa-host.exe list 10
```

- `search <关键词>`：命中文本与文件路径
- `pin <id>` 后 `clear`：置顶条目保留，其余清空
- `copy <id>`：条目回到剪贴板，可直接 Ctrl+V

## 3. 历史面板（本轮新增）

1. 光标停在任意可输入处，按 `Ctrl+Shift+V`（被占用时自动回落 `Alt+V`，
   监听进程启动时会打印实际生效的热键）
2. 面板弹出在光标附近，显示最近 9 条：序号、类型标记（图/件/★置顶）、预览
3. `↑`/`↓` 移动选择，回车粘贴；或直接按数字 `1-9` 选中即粘贴
4. 被粘贴的条目浮到历史最顶（去重刷新时间戳的自然结果）
5. `Esc` 或点击面板外任意处关闭
6. 图片条目回车后，在画图/Word 里 Ctrl+V 应还原图片（CF_DIB 回填）

## 已知边界

- 面板不含搜索框（键入过滤计划随设置界面一起做）
- 粘贴目标是呼出面板瞬间的前台窗口；呼出后手动切走前台再回车，
  粘贴会落在新前台窗口
- 提权（管理员）窗口收不到普通权限进程的模拟按键，此时条目已在
  剪贴板中，手动 Ctrl+V 即可
