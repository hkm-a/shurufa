## 0. 为什么以搜狗时间线作为排期依据

搜狗输入法 17 年的功能演进是一条可观察的"输入法能力成熟度曲线"，出现顺序大致是：

1. **先把打字核心做扎实**（性能、纠错、候选、混输、生僻字）；
2. **再补个性化与效率工具**（皮肤/字体、输入统计、工具箱、表情/颜文字、标点配对）；
3. **然后做跨端与系统适配**（词库同步、高分屏、Win11/ARM64、无障碍）；
4. **随后全面 AI 化**（写作助手 → 智写 → AI 汪仔 → AI 划词/光标助手）；
5. **最后回头重构入口与体验**（候选条、跨设备复制粘贴、设置中心）。

Shurufa 已走完第 1 步，并部分完成第 2、3 步（v0.7.x）；本计划按时间顺序把
第 2 步收尾、第 3 步深化与第 4、5 步整合排进后续里程碑——顺序即优先级：
先打字体验，再跨端，再 AI 与设置入口，最后专业与无障碍。

## 2. Shurufa 现状盘点（v0.7.1）

- **输入**：雾凇拼音 + 小鹤双拼、MRU 提频、音节分词、Shift/CapsLock/Ctrl+. 切换、
  V 模式（日期/金额/计算器/农历）、以词定字、辅码检字、错音提示、冷词丢弃、
  Emoji 候选、Unicode 输入、符号配对、中英混输自动空格、长候选缩写、候选来源角标、
  按应用英文/vim、英文自动大小写、词汇别名、自定义短语、用户词库管理、候选窗位置策略。
- **桌面**：FOX 悬浮球、皮肤系统（5 预设 + JSON 编辑 + 热生效）、候选窗 DComp/D2D/GDI
  瀑布渲染、模式切换 toast、符号面板（emoji 分类/肤色记忆/最近使用/颜文字/搜索）、
  剪贴板历史、AI 帮写/划词润色/划词翻译（Ctrl+Shift+W/R/T）、语音转写入口。
- **跨设备**：剪贴板文本/图片/文件双向同步（协议 v3：分块校验 + 回执）、文件接收审批、
  剪贴板收藏、自托管中继、云词库多代回滚、按来源设备/类型筛选。
- **工程**：全工作区 clippy/fmt 零告警、145+ 测试、CI 双平台、version.json 单一事实源。

详细落地证据见 [CHANGELOG](../CHANGELOG.md) 与 [优化灵感库](优化灵感库.md)。

## 5. 执行节奏与验收

1. **每轮迭代** = 一个 0.x MINOR：从对应里程碑取 P0/P1 条目，拆成可验收切片。
2. **切片完成** → 单测/集成测试 → 实机验证 → 更新 CHANGELOG（Unreleased）。
3. **里程碑完成** → 全量 `cargo test --workspace --locked` + clippy/fmt + 双平台构建 →
   写验收报告 → bump 版本（[版本管理](版本管理.md)）→ 更新本文状态与 README。
4. **跨阶段红线**：打字体验（候选/延迟）任何改动不得劣化既有延迟预算；
   AI 功能一律可开关、可自选服务；剪贴板协议保持向后兼容。
