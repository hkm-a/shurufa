## hosted 右键菜单与固定位置

- 右键候选弹出菜单：从候选删除 / 降低词频 / 隐藏该词 / 打开设置中心。
- 菜单动作经 `CandCommand::MenuAction` 回传 TSF，由 TSF 模拟引擎键序。
- `CandEvent::Show` 增加 `position`，hosted 支持 `follow / bottom_left / bottom_right`。

## hosted 多行布局与完整皮肤

- `CandEvent::Show` 增加 `multi_line` 字段，TSF 按 `candidate_panel_mode` 传递。
- `cand_host` 支持多行候选面板布局（每行 5 项自动换行）。
- 完整皮肤：Win11 圆角、深色边框、透明度、阴影壳（`windows_skin::apply_appearance` + `ShadowShell`）。

## AI / 英文候选已迁入 hosted

- AI 候选结果由 worker 写入共享缓存，`CandidateUi::show` 推帧前合并到候选列表（机器人副标）。
- 引擎无候选时自动补英文联想，随 hosted 帧一起显示。
- 点击/数字选词仍走 CandCommand -> TSF 虚拟键合成，与普通候选一致。

## 内置绘制路径已删除

- TSF 侧 `candidate_window.rs` 重写为 hosted-only，不再创建/绘制候选窗口。
- 删除 `candidate_window_d2d.rs` 及全部 GDI/D2D 内置绘制代码。
- 全屏/管道故障不再回退内置；hosted 不可用时仅不显示候选，输入不受影响。

## 本次修复

- `cand_client.rs`：读线程改用 `read_frame_timeout` 轮询，避免同一管道句柄上
  阻塞 Read 与 Write 并发导致 hosted 连续输入卡死。
- `candidate_window.rs`：show/hide 写失败时丢弃旧客户端并回退内置，避免管道断开后假死。
- `test-cand-manual-auto.py`：改用 SendInput scancode 发送真实键盘事件，
  pywinauto send_keys 的 Unicode 直插不会被 TSF 当作按键处理。
