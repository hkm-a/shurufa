## 二、重要实测结论

- **提示词三段式**：模式 system + 风格指令 + 场景指令拼接（AiPrompt.kt 纯函数），
  单测锁死各模式区分与指令注入；callAgnesChat 增 system 参数，默认值保持旧行为。
- **真实 API 依赖用户 Key**：Android 端 agnès Key 由 BuildConfig 打包注入
  （gradle 属性 AGNES_API_KEY），本机 debug 包未内置 Key，AI 面板显示「未配置」；
  实机冒烟验证面板/模式切换不崩溃，真实调用留用户验证（与 PC M9 一致口径）。
