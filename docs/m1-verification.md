# M1 Windows TSF 前端：手工验收清单

自动化测试无法覆盖 TSF 与真实应用的交互，本清单由人工执行并回填结果。
执行前提：`cargo build -p shurufa-tsf` 已完成。

正式安装、升级与卸载使用 [Windows 安装文档](windows-installation.md)；本页保留
开发期注册和真实应用兼容性验收步骤。

## 1. 注册（管理员）

以管理员身份运行：

```bash
scripts/register-dev.cmd
```

脚本会把 `shurufa_tsf.dll`、`rime.dll` 与 `schemas/` 部署到
`%ProgramData%\shurufa` 并授予 AppContainer 进程读取权限
（Win11 的输入切换器 TextInputHost.exe 运行在 AppContainer 中，
读不了用户目录下的 DLL——直接从仓库注册会导致切换失败、
输入法从列表消失）。

预期：弹窗提示 DllRegisterServer 成功；`设置 → 时间和语言 → 语言和区域 →
中文（简体，中国） → 语言选项 → 键盘` 中出现「Shurufa 拼音」。

> 注意：
> - **每次重新构建后必须重跑本脚本**刷新部署副本。
> - 注册后建议注销重登一次，清掉旧注册在各进程中的残留映射。
> - 排障日志在 `%TEMP%\shurufa-tsf.log`（每个宿主进程各自的 TEMP 下）。

## 2. 功能验收矩阵

正式安装后，Shurufa 拼音会成为当前用户的默认输入法并立即在当前会话激活；在每个应用中
直接输入下表操作即可。开发期反复注册或已被其他输入法切走时，才需要手动切回。

| 验收项 | 操作 | 预期 |
|---|---|---|
| 组合显示 | 输入 `nihao` | 文档内联显示拼音预编辑串，候选窗在光标下方出现，首选「你好」 |
| 空格上屏 | 继续按空格 | 「你好」落入文档，预编辑串与候选窗消失 |
| 数字选词 | 输入 `nihao` 后按 `2` | 第二候选上屏 |
| 翻页 | 输入 `zhang` 后按 `-`/`=` 或方向键 | 候选翻页/高亮移动，候选窗跟随刷新 |
| 回删 | 输入 `nihao` 后按退格 | 预编辑串逐字母回删，删空后候选窗消失 |
| 取消 | 输入 `nihao` 后按 Esc | 预编辑串清空，不产生任何文本 |
| 标点直通 | 无预编辑时按 `,` `.` | 由应用按原样处理（M1 暂不做中文标点） |
| 英文直通 | Ctrl/Alt 组合键、F 键区 | 快捷键不被吞，行为与未开输入法一致 |
| 焦点切换 | 组合中途点击文档其他位置 | 组合终止，无残留半成品文本 |

### 运行证据（2026-08-03）

- Debug 原生验收命令 `shurufa-host tsf-native-probe` 已在本机通过：它创建系统 `EDIT` 控件、确认前台焦点后发送系统键盘消息。探针确认候选窗可见且贴近编辑控件，数字 `1` 与空格均完成“nihao → 你好”，五次退格和 Esc 均清空组合并隐藏候选窗。`%TEMP%\\shurufa-tsf.log` 逐键记录了这些路径的 TSF 消费、预编辑与提交状态。
- 当前用户默认 TIP 读回为
  `0804:{8A5C1B49-3D2E-4F7A-9C61-0B7E2D5A9F13}{C4E9D2A7-6B31-4A58-8F0D-1E9A7C3B5D26}`，
  TSF COM 注册路径为 `%ProgramData%\\shurufa\\shurufa_tsf.dll`。
- `%TEMP%\\shurufa-tsf.log` 记录 `chrome.exe` 的真实按键处理：`lao ban` 后按数字键
  `1` 提交“老板”、`fa cai` 后按 `1` 提交“发财”，每个拼音按键均被 TSF 消费。
- 同一日志还记录 ChatGPT 桌面客户端输入 `xue xi` 后按数字键 `1` 提交“学习”，作为
  非浏览器编辑控件的补充运行证据。
- 本机自动化能力本轮仅暴露 ChatGPT 窗口，未暴露记事本、Chrome、VS Code、Word 或
  Windows 终端的可操作窗口。因此候选窗定位与快捷键直通不能以文本注入或无窗口结果替代，
  上表保留待测状态。

## 3. 已知限制（M1 范围内接受）

1. 独立算法服务与命名管道已在 M6 落地，词典也在安装时预构建；本条不再适用。
2. 未实现 Shift 切换中英文的完整键抬起语义；中文标点与全半角由雾凇方案的
   `ascii_punct`、`full_shape` 开关和快捷键提供。
3. 候选窗已按 DPI 和文本宽度布局并使用共享皮肤颜色；尚未按 Windows 系统主题自动切换深色皮肤。
4. 管理员权限运行的应用中，非管理员注册的输入法可能不可用（TSF 惯例），
   属系统行为。
5. UWP/沉浸式应用已声明支持类别，但候选窗定位未按 UILess 模式实现，
   在全屏 UWP 下可能遮挡。

## 4. 反注册

以管理员身份运行 `scripts/unregister-dev.cmd`，确认输入法从键盘列表消失。
