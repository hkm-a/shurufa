## 二、重要实测结论

- **修复 UIA Provider 引用计数缺陷（全量回归暴露）**：上次"泄漏一个引用"的修法
  只覆盖一次 from_raw 包装——第二次调用 provider() 后对象即被释放，全量跑
  shurufa-tsf 时复现 0xc0000374 堆损坏；改为静态持 1 引用 + 每次调用前 vtable
  AddRef，全量 40 组回归全绿（8a4166e）。
- **工具栏配置模型**：显隐 = 从持久化列表移除/追加；排序 = move 上移/下移；
  resolve 保证已存顺序优先、缺省项按全量顺序补齐、非法 id 过滤（JVM 单测锁定）。
- **功能行收敛**：9 个入口的渲染从 onCreateInputView 内联改为 renderFunctionRow
  （按配置），未来新增入口只需在 toolbarItems() 注册，天然进入自定义范围。
- **场景词库**：M10 已把医生/律师/代码/生僻字词条内联进 rime_ice.dict.yaml，
  Android 与 PC 同词库，场景词无需再切换即生效（引擎测试覆盖 zhuanyeciku、
  weng→齆、niuniuniu→犇 等）。
- **实机缺口**：本机 adb 断开，APK 1.7.0 构建产物就绪但未实机安装；词库每日
  更新的增量拉取与工具栏实机手感留用户验证。
