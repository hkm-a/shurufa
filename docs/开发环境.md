# 开发环境

> 所有构建/打包/安装脚本只支持 **PowerShell 7+**（`pwsh`），不支持 Windows PowerShell 5.1 的传统字符集行为；所有命令默认在仓库根目录执行。

## 首次克隆后的三件套

```powershell
# 1. 拉预编译 librime（Windows 桌面引擎）
New-Item -ItemType Directory -Force third_party\librime | Out-Null
Invoke-WebRequest -Uri https://github.com/rime/librime/releases/download/1.17.0/rime-33e7814-Windows-msvc-x64.7z `
  -OutFile third_party\librime\rime.7z
7z x -y third_party\librime\rime.7z -othird_party\librime

# 2. Android NDK + Rust 交叉 target
rustup target add aarch64-linux-android x86_64-linux-android

# 3. Tauri 前端依赖
npm --prefix platforms/windows-settings ci
```

## 各平台入口

- **Windows 安装包**：`scripts\build-installer.ps1`（`-SkipBuild` / `-Sign` 可选）。产物 `dist\Shurufa-Setup-<version>.exe` + `.sha256`。
- **Android APK**：`scripts\build-android.cmd`（内部已负责 `shurufa-rimejni` 的 aarch64 交叉编译与拷入 `jniLibs`）。产物按版本号命名于 `platforms\android\app\build\outputs\apk\versioned\`。
- **本机直接部署**（跳过 NSIS）：`scripts\install.ps1`，与安装器共用 `installer\Deploy-Shurufa.ps1` 部署路径。
- **版本 bump**：`scripts\set-version.ps1 -Version 0.4.2 -VersionCode 11`，详见 [发布流程](发布流程.md)。
- **自托管中继**：`cargo run -p shurufa-relay`，详见 [自托管中继](自托管中继.md)。

## 目录约定

- 构建产物：`target\`、`platforms\android\app\build\`、`platforms\windows-settings\ui-dist\` —— 不入库。
- 安装产物：`dist\` —— 不入库，正式分发取自 CI Release 资产。
- 预编译依赖：`third_party\librime*` —— 不入库，按 `version.json` 锁定版本手工或 CI 拉取。
- 词库与皮肤：`schemas\` —— Windows 与 Android 共同读取的单一事实源，不要在两端维护副本。

## 终端/脚本运行约定（重要）

本机已安装 PowerShell 7 与 WSL，一律不要使用 Windows PowerShell 5.1（`powershell.exe`）执行项目脚本：

1. PS 5.1 把原生命令（adb、cargo、gradlew）的 stderr 输出（即使命令成功）当作终止错误，`$ErrorActionPreference='Stop'` 下一启动就挂；PS 7 已修复。
2. 历史脚本曾为兼容 PS 5.1 写过 `2>&1 | ForEach-Object { "$_" }` 之类规避写法（见 `scripts/test-android-attachments-emulator.ps1` 的 `Invoke-Checked`），现已只维护 PS 7 路径。
3. 所有后台长任务（模拟器测试等）统一用 `pwsh` + 日志重定向运行。

执行约定：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\xxx.ps1
```

Android SDK / adb 默认查找路径：`%LOCALAPPDATA%\Android\Sdk`；JDK 17：`C:\Program Files\Microsoft\jdk-17.0.20.8-hotspot`。

## 模拟器与真机自测

- `scripts\test-android-attachments.ps1`（真机）/ `scripts\test-android-attachments-emulator.ps1`（模拟器）：附件投递回归。
- `scripts\test-background-image-sync-emulator.ps1`：Windows↔Android 图片同步端到端。
- 后台跑全量模拟器验收可用 `pwsh -NoProfile -ExecutionPolicy Bypass -File .\.claude\run-emulator-tests.ps1 -KeepEmulator`（输出重定向到 `.claude\emulator-tests.log`）。
