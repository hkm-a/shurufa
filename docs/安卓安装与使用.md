# Android 安装与使用

## 安装

1. 从 [Release](https://github.com/hkm-a/shurufa/releases) 下载 `shurufa-<版本>-<code>-debug.apk`，或自行构建（见 [开发环境](开发环境.md)）。
2. 在手机上打开 APK 文件完成安装（需允许"安装未知来源应用"）。
3. 进入 **设置 → 系统 → 语言和输入法 → 屏幕键盘 / 虚拟键盘**，启用 **Shurufa**。

## 切换为默认输入法

- 任意输入框长按 → 选择"输入法"→ Shurufa；或
- 下拉通知栏点击"选择输入法"→ Shurufa。

## 键盘功能

| 手势 / 按键 | 行为 |
| --- | --- |
| 中英文切换键 | 在雾凇拼音中文与英文直输之间切换 |
| 拼音中点击光标 | 在已有拼音串中精准插入/删除（引擎级光标） |
| 候选词左滑 / 上滑 | 翻页查看更多候选 |
| 候选词长按 | 复制、置顶或删除（自定义词频） |
| 退格键上滑 | 一键清空当前拼音与候选 |
| `?123` / `符` | 数字与符号页 |

## 剪贴板同步

与 Windows 桌面端在同一局域网自动发现并同步：

1. 确保手机和电脑在同一 Wi-Fi。
2. 电脑端打开 **Shurufa 控制中心 → 同步**，保持默认端口。
3. 手机端打开 **Shurufa 设置 → 剪贴板同步**，应能看到电脑设备在线。
4. 复制文本或图片后，另一端几秒内出现在剪贴板历史中。

如需跨网段/移动网络同步，在自托管中继上部署 `shurufa-relay`，并在两端填中继地址，详见 [自托管中继](自托管中继.md)。

## 词库更新

设置 → 词库，可查看当前 rime-ice 版本并手动触发更新；默认锁定版本经 SHA-256 校验，镜像失败自动回退 GitHub Raw。

## 卸载

系统设置 → 应用 → Shurufa → 卸载。用户词库与同步配置保存在应用私有目录，卸载即删除；如需保留请先导出。
