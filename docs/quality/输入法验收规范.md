## 本波新增 · 性能钩子脚本（独立可跑）

**目的**：R2.1/R2.3 给到**自动可重复**证明，每次大改完跑一次用来当 regression gate。

- `tools/bench_keypress.py`：
  - 使用 `pyautogui`（或 ctypes SendInput 封装）触发真实键序
  - 从 tsf Notepad 目标窗上屏时间戳差算 keys-to-commit ms
  - 打 1000 次随机合法拼音 + 50 组边界（`shang'hai` / `ce'lu:e` / 大小写切换 / 中英混合）
  - 调用 shurufa-algo  `--once` 读取 `RSS(PagefileUsage)` 前后变化
  - 将结果写 `target/bench/report-{ts}.json` + 简洁 markdown 表
  - Exit code 0 = p95 < 50ms && RSS 波动 < 5%

本脚本一旦就位 + 附录 Q 涉及的功能代码（wave 5）合入后，此 R 标准立刻成为**git-status clean + cargo test 全绿 + python 自检 0** 的三位一体 gate。
