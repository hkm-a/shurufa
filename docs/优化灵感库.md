### 当前 schema 盘点结论（Shurufa rime_ice.schema.yaml）

- ✅ 已有：模糊音（n/l、前后鼻音硬编码）、英文混输、英文自动大小写、词汇别名、部件拆字辅码（search.lua）、vhelp 帮助、MRU 提频、整句造词（max_sentence_length=8）、拼音纠错（NearSearch）、以词定字、错音错字提示、V 模式转写、辅码检字（uU）、冷词丢弃、自定义短语、Emoji
- ❌ 缺失（rime-ice 有但我们没启用）：简繁切换（需 .ocd2 数据）、v 前缀符号体系（我们沿用 `/` 前缀 + 符号面板）
- 设计取舍：当前 schema 是"轻量 + Lua 增强"混合版——V 模式/错字提示/辅码等已通过 librime-lua 通道启用
- 2026-08-17 方向（成熟输入法更新日志研究）：英文自动大小写 + 词汇别名 + vhelp + 部件辅码 + 按应用自动英文已落地；符号配对、show_notifications、按应用更多选项（vim_mode 等）列入后续候选
- 2026-08-18 方向（show_notifications）：模式切换 toast 提示已落地（#28）；host 侧事件（划词翻译完成、方案切换完成、剪贴板复制）接入 toast 需 host→TSF 命名管道，列入后续候选；按应用更多选项（vim_mode 等）仍在候选
- 2026-08-18 方向（搜狗 6.24.1 更新日志）：符号面板增强已落地（#29，emoji 分类 + 肤色记忆 + 最近使用 + 颜文字）；emoji 面板搜索、emoji 快捷键联想输入（输入关键词出 emoji 候选）列入后续候选
- 2026-08-18 方向（rime-ice emoji 机制调研）：emoji 关键词联想验证为已完整（#30）——rime-ice 无拼音词典，走 simplifier@emoji 词→emoji 附加候选，我们配置与上游逐字节一致；已补回归测试。真正可做的新方向：emoji 面板搜索（设置页）、v 前缀符号体系切换（沿用 / 前缀 + 符号面板，不追 rime-ice 的 v 符号）
- 2026-08-18 方向（weasel app_options 源码调研）：按应用 vim 模式已落地（#31）——镜像 RimeWithWeasel.cpp 的 vim_mode 语义（Esc/Ctrl+C/Ctrl+[ 回 normal 模式自动切英文）；weasel app_options 是通用 string→bool 映射（可扩展任意 option 名），我们按需实现了 ascii_mode + vim_mode，inline_preedit（应用内联预编辑）列入候选
