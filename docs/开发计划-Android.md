## 0. 为什么以搜狗安卓时间线作为排期依据

搜狗输入法 Android 版 17 年的功能演进呈现一条清晰的"移动输入法能力成熟度曲线"，
出现顺序大致是：

1. **先把基础输入做扎实**（拼音/词组/联想/词库/手写/笔画/皮肤起步/云输入）；
2. **再做语音与多媒体**（语音输入、二维码、超级键盘混输、双拼、表情、滑行、单手）；
3. **然后构建个性化生态与无障碍**（皮肤商城、手写升级、斗图、游戏键盘、无障碍输入、
   跨屏、妙算/Big Bang、智能汪仔萌芽）；
4. **随后全面 AI 化**（汪仔 2.0 → AI 写作助手 → AI 输入 → AI 语音/翻译/皮肤/快查）；
5. **最后整合跨端与设置**（自定义短语专属候选栏、跨设备复制粘贴、工具栏自定义、
   设置极简、词库每日更新）。

Shurufa Android 已具备 librime 内核 + 雾凇拼音、26 键/表情/符号、方案切换、
语音（系统识别）、AI 帮写（agnès）、跨设备剪贴板 v3、TalkBack 候选朗读。
本计划按时间顺序把缺口收尾、把第 3/4/5 步的能力落地进里程碑——顺序即优先级：
先键盘形态与输入效率，再表达效率工具，再无障碍与生僻字，再 AI 助手，最后跨端生态与设置。

## 2. Shurufa Android 现状盘点（2026-08-19）

- **输入**：librime（libshurufa_rime.so，arm64/x86_64）＋ 雾凇拼音；全拼/简拼/中英混输/
  emoji 候选/错音提示/上下文调频等随 PC schema；26 键 QWERTY + emoji + 数字符号页
  （JSON 布局驱动）；方案切换面板（双拼/五笔/仓颉/笔画/英文 schema 已随包）；引擎预热
  队列；候选分页/长候选/候选操作（复制/删词/置顶）。
- **语音**：系统 SpeechRecognizer 在线识别，长按空格说话、无缝轮转防超时；无离线、
  无翻译、无口语转书面语。
- **AI**：agnès chat 流式帮写面板（键盘内 AI 面板 + 历史），Key 走 gradle.properties/
  运行时读取；无 AI 快查/翻译/语音转写。
- **跨设备**：剪贴板文本/图片/文件双向同步（协议 v3）、设备配对向导、后台同步服务、
  云词库更新、图片历史/斗图面板、附件投递策略（SEND intent/剪贴板兜底）。
- **无障碍**：候选词 contentDescription + TYPE_WINDOW_CONTENT_CHANGED（TalkBack 可读，
  v1.2 已交付）；无声文互转/触觉输入。
- **皮肤与外观**：浅色/深色跟随系统（SkinPalette），无自定义皮肤/壁纸/字体。
- **统计**：今日/累计打字字数。
- **设置面**：MainActivity 首页卡片（同步/AI/皮肤）+ Onboarding；键盘内无快捷设置弹层。

## 5. 执行节奏与验收

1. **每轮迭代** = 一个 MINOR（v1.3.x 起）：从 M-A* 里程碑取 P0/P1 条目，拆成可验收切片。
2. **切片完成** → JVM 单测 + 实机验证（adb，Redmi 23113RKC6C）→ 更新 CHANGELOG（Unreleased）。
3. **里程碑完成** → 全量 cargo test --workspace --locked + clippy/fmt + gradle assembleDebug
   + set-version.ps1 -Check → 写验收报告 → bump 版本 → 更新本文状态与 README。
4. **跨阶段红线**：打字体验（候选/延迟）不得劣化既有延迟预算；AI 功能一律可开关、
   可自选服务；剪贴板协议保持向后兼容；TalkBack 候选朗读（v1.2）不得回归。
