# M4 安卓端验收：手机接收电脑剪贴板

安卓同步接入。安全模型与桌面一致（自签证书、六位确认码、TLS 1.3
双向认证 + 指纹钉扎）。安卓端取舍：关闭 mDNS（省电策略下不可靠），
手机作发起端输入电脑 IP 直连；入站条目走轮询。

产物：`platforms/android/app/build/outputs/apk/debug/app-debug.apk`
（约 16MB，因内置 tokio+rustls+ring）。

## 前置

1. 电脑与手机同一 Wi-Fi
2. 电脑运行 `scripts/start-host.cmd`，`shurufa-host devices` 记下电脑 IP
   （或 `ipconfig` 查无线网卡 IPv4）

## 配对（自动发现，免输 IP）

1. 手机装 APK，打开「Shurufa 输入法」应用图标（进配对页）
2. 电脑端运行 `scripts/start-host.cmd` 后，配对页「发现的电脑」区几秒内
   自动出现电脑（NsdManager 发现 `_shurufa._tcp`）；点击该条即发起配对
3. 手机与电脑几乎同时显示**六位确认码**（电脑弹对话框，手机显示大字）
4. **核对两码一致**：手机点“一致，确认”，电脑点“是”
5. 手机配对页“已配对设备”出现电脑名；电脑 `shurufa-host devices` 出现手机

> 自动发现失败（部分路由器隔离多播）时，用配对页下方“手动输入”填电脑
> IP 兜底（`shurufa-host devices` 或 `ipconfig` 查无线网卡 IPv4）。

## 同步验收（双向）

**电脑 → 手机**：
1. 电脑任意处复制文本
2. 手机呼出键盘，顶部橙色条显示「来自 <电脑名>：…（点此上屏）」，点按上屏
3. 该条也进入手机剪贴板历史（键盘左上 ⊞ 按钮查看）

**手机 → 电脑**：
1. 手机在任意应用复制文本（浏览器选中复制等）
2. 切到带输入框的应用，**呼出 Shurufa 键盘**——此刻输入法在前台，读取
   系统剪贴板并推送电脑（安卓 12+ 会有一次“输入法访问剪贴板”系统提示）
3. 电脑上 `Ctrl+Shift+V` 历史顶部出现该条，来源「同步·<手机名>」

**手机端历史面板**：键盘左上 ⊞ 按钮展开，列出本机复制与同步收到的记录，
点任意条上屏，再点 ⊞ 返回键盘。

**图片同步（电脑 → 手机）**：
1. 电脑上截图或复制一张图片
2. 手机呼出键盘，顶部橙色条显示「来自 <电脑名>：收到图片（点此上屏）」
3. 在支持图片的输入框（微信、邮件、社交类）点该条 → 图片经 commitContent
   直接上屏；纯文本输入框不支持则静默（图片仍进历史）
4. 点键盘左上 ⊞ 打开历史面板，图片以缩略图显示，点缩略图上屏

## 已知边界

- **手机 → 电脑仅在键盘弹出时捕获**：安卓 10+ 禁止后台应用读剪贴板，
  只有输入法在前台（键盘弹出）时能读系统剪贴板；用户复制后需呼出一次
  键盘才会同步。这是平台约束，与微信输入法同理。
- **文本与图片双向同步**（图片经 BMP↔PNG 转换）；文件（多文件列表）暂不同步
- **手机 → 电脑图片**：手机复制/截图后呼出键盘，输入法读系统剪贴板图片
  （content:// URI → 解码 PNG，过大自动降采样到 2000px），推送电脑入历史库
- **图片上屏依赖输入框支持**：commitContent 需目标输入框声明 image/png，
  微信/邮件等支持，纯文本框不支持（图片仍可从历史面板查看）
- 手机重启或长时间后台后，需再次呼出键盘触发同步服务启动
- 自动发现依赖局域网多播；企业/公共 Wi-Fi 常隔离多播，用手动 IP 兜底
