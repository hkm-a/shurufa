# 搜狗输入法研究——布局与功能设计借鉴（2026-08-20）

> 研究对象：搜狗输入法 Android 20.14.0（versionCode 2590，`com.sohu.inputmethod.sogou`，
> 豌豆荚 CDN 下载）。反编译手段：aapt2（SDK）dump 资源 + androguard 4.1.4 分析 dex（8 个 dex、
> 62,302 类，代码未混淆，包名完整）。

## 一、总体架构

### 1.1 IME 服务与输入视图

- `SogouIME` → 继承 `BaseInputMethodService`（包 `com.sogou.bu.ims.support`）→ 继承系统
  `InputMethodService`。生命周期钩子齐全：`onStartInputView/onFinishInputView/onStartCandidatesView`
  等，`setInputView()` 统一注入根视图。
- 根视图 = `KeyboardRootComponentView`（`com.sogou.bu.ui.keyboard`）→
  `BaseKeyboardRootComponentView`（`com.sogou.imskit.core.ui.keyboard.view`）→
  `RootComponentView`（`imskit/core/ui/virtualwidget/component`）。

### 1.2 组件化键盘框架（imskit）

`com.sogou.imskit.core.ui.keyboard` 是独立键盘 UI 框架，按能力分包：

| 包 | 职责 |
| --- | --- |
| `component/` | `KeyboardAnimComponent` 键盘动画组件 |
| `floating/` | 悬浮键盘（FloatType / layout / move / switchs） |
| `resize/` | 键盘缩放（data/attributes/scale + keyboard/config + layout/limit） |
| `resize/singlehand/` | 单手键盘（`SingleHandKeyboard`） |
| `factory/` | 键盘工厂 |
| `view/` | 根组件视图 |

### 1.3 候选引擎分层（com.sogou.core.input.chinese）

- `engine/base/candidate`：`CandUpdateState / CandsUpdateMode / MoreCandsAction / TouchUpStatus /
  SymbolInputType` —— 引擎候选状态机。
- `engine/candidate`：`CandCodesInfo / CandsInfo`（含 `CandsMode`）—— 数据模型。
- `inputsession/candidate`：`CandsViewData`（`UpdateCloudSinkResult / UpdateGenerateCandResult`）——
  会话层合并云端候选与本地生成候选，单一数据源驱动 UI。
- UI 层：`HkbHorizontalCandidatesPageView`（横向分页）/ `HkbVerticalCandidatesView`（纵向列表），
  候选栏支持横滑与分页。

## 二、布局设计要点

### 2.1 按键气泡预览（重点借鉴）

- `com.sogou.bu.keyboard.popup`：`AbstractKeyPopupView` / `KeyboardPopupView` /
  `DirectionalKeyboardPopupView`（按方向放置）/ `KeyboardPopupHelper`（弹出计时）。
- `popup/style/KeyPopupViewLayout` + `style/a..m`：气泡的**绘制样式对象**（位置计算 v(I)I、
  样式注入 setDrawingStyles）。
- 能力：`setText(主字符, 副字符, 索引, …)`、`setPreviewIcon(图标, Rect)`（符号/表情预览）、
  `setCodesInLongPressed([I)`（长按多候选：á à â…）、`onDraw` 自绘气泡（非简单 ImageView 弹窗）。
- 要点：气泡是自绘 View（Canvas 绘制圆角矩形+文字+小三角），可主题化；弹出位置由
  `KeyPopupViewLayout` 做方向/越界计算。

### 2.2 单手键盘（SingleHandKeyboard）

- 继承 `LinearLayout`；按 `button/layout/params` 逐键布局，支持场景切换（`setButtonScene`）、
  子页折叠（`setSubPageFolded`）、按钮增删（`setButtonClickListener`）。
- 说明文案「单手拇指自然向外侧画一个扇形」——单手模式按拇指活动范围扇形排布。

### 2.3 键盘切换与工具条

- `KeyboardSwitchPager`（BasePager）：键盘页与工具页用 **Pager 滑动切换**，而非整面板替换。
- `ToolsAndKeyboardSwitchItemView`：工具条与键盘切换的单项视图。

### 2.4 功能入口（字符串面，11,081 条去重）

| 功能 | 说明 |
| --- | --- |
| 滑动输入 | 「向上滑动输入数字或符号」「同时向两侧滑动开启分离键盘」 |
| 单手键盘 | 拇指扇形布局；大九键/全屏手写不支持单手 |
| 悬浮键盘 | 悬浮窗权限 + 悬浮键盘（布局/移动/切换全套） |

| 语音（119 条） | 录音权限自修复、麦克风占用提升优先级、QQ 直发语音 |

## 二·补充、真机交互观察（Redmi K70 / 搜狗小米版 10.32.21，2026-08-20）

- **QWERTY 全键盘**：四行字母 + 每键右上角副字符（Q-P 上 1-0，A-L 上符号），
  底栏 分词/符/123/,/./中英。与我们布局一致，验证了 P1a 滑动上屏的副字符设计。
- **按键气泡**：按 W 键在键上方浮动放大「w」气泡（键盘设置里有「按键气泡提示」开关），
  与我们的 P0 KeyPopupView 同模式。
- **候选栏**：主行 6 候选 + 左滑展开**编号候选列表**（1-9 编号、表情混排），
  右侧功能竖栏 返回/重输/拼/笔/全/字（模式切换）。我们已有展开列表+翻页，
  可借鉴：编号候选、表情混排、右侧模式切换竖栏。
- **扩展候选**：搜狗展开后候选带编号（2 晚 3 王 4 为 5 万…），首候选蓝色高亮。
- 注：搜狗小米版上滑字母键实测输入主字符（副字符上滑可能需设置开启）；
  我们的 P1a 直接实现了上滑输副字符，符合搜狗宣传字符串「向上滑动输入数字或符号」。

## 二·UI、布局与设置设计全景（反编译 + 真机小米版 10.32.21 对照）

### UI-1 布局设计（键盘）

- **QWERTY**：4 行字母 + 候选栏 + 功能行；字母键右上角副字符（Q-P 上 1-0、A-L 上符号），
  支持上滑/长按输副字符——与我们 P1a 一致。
- **按键气泡**：按下在键上方浮动放大字符（设置里「按键气泡提示」可关）——与我们 P0 同模式。
- **T9 九键**：数字格 + 分词/重输/大发送键，键盘设置里有「拼音九键显示分词」「9键启用大发送键」。
- **候选栏**：主行 6 候选（首候选蓝底高亮）+ 左滑展开**编号候选列表**（1-9 编号、表情混排），
  右侧功能竖栏 返回/重输/拼/笔/全/字（模式切换）。
- **架构**：imskit 组件化（floating 悬浮 / resize 缩放 / singlehand 单手 / anim 动画），
  键盘 UI 代码自绘（非 XML 布局）——与我们的 WetypeKeyboardView + KeyPopupView 自绘路线一致。

### UI-2 设置设计（自研 Preference 框架）

- 结构：`AbstractSogouPreferenceActivity` + 每功能一个设置 Activity
  （InputSettings / KeyboardSettings / HandWritingSettings / VoiceSettings / DictSettings /
  EnglishSettings / DoubleInputSettings / ElderModeSettings / UncommonWordSettings /
  DataSyncSettings / PrivacySettings / TalkbackSettings / QuickSearchSettings …）+ MVVM ViewModel。
- 控件库（`com.sogou.lib.preference`，代码构建）：
  `SogouCategory`（分组标题）、`SogouSwitchPreference`（开关）、`SogouSeekBarPreference`（滑块）、
  `SogouRadioGroupPreference`/`SogouTipRadioButtonPreference`（单选组）、`SogouButtonPreference`、
  `SogouLinkPreference`、`SogouTwoCheckBoxPreference`、`seek/BaseSeekSwitchPref`（滑块+开关组合）、
  `SogouDividerPreference`、`SogouRoundBannerPreference` 等。
- 设计模式（真机实测）：
  1) **分组标题 + 开关项 + 灰色说明副文本**（语音设置：识别设置/个性设置两组，每项带用途说明）；
  2) **滑块+实时预览+取消/保存 模态弹窗**（候选字大小：滑块调大小，预览「你好」实时变化）；
  3) **单选组样式选项**（手写：笔锋效果 书法/经典/清秀/圆头；笔迹颜色 默认/自选+色板）；
  4) **实时预览区**（手写设置顶部实时显示书写效果）。

### UI-3 整体设计语言

- 白底、行式列表（图标+文字+右侧箭头），分组标题分隔；主色调橙色（Logo/按钮）。
- 首次启动两步引导（启用→切换），步骤完成打 ✓。
- 设置页 feature-scoped（一功能一页），状态用 ViewModel 驱动。
