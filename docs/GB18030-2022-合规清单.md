# GB18030-2022 合规清单与生僻字输入覆盖（v1.2）

> 对应计划：M10-4 GB18030-2022 / M10-5 生僻字字库扩充（评估见 [M10-评估报告](M10-评估报告.md)）
> 落地日期：2026-08-19（v1.2 生僻字词库包）

## 一、结论

GB18030-2022 强制集约 8.7 万码位（含 CJK 统一表意文字扩展 A-G）。Shurufa 的输入策略：

| 需求 | 能力 | 路径 |
|---|---|---|
| **能输入任何 GB18030-2022 汉字** | 任意码位可输入 | U + 十六进制码点 兜底（schemas/lua/unicode.lua，已实装，引擎集成测试覆盖） |
| **按拼音打出常用生僻字** | 8105 + 449 常用生僻字 | 规范字表 8105（默认部署）+ scenario_rare.dict.yaml（v1.2 新增） |
| **按拼音打出全部扩展区字** | 按需启用 | rime-ice 41448 大字表（rime_ice.dict.yaml 注释已给启用方式；全量启用体积大、命中率低，不做默认） |

**不建议**为 GB18030-2022 全量 8.7 万码位建拼音词库：多数扩展区字无常用读音共识，性价比极低；
「合规」= 能输入（U+ 兜底已满足），而非拼音全覆盖。

## 二、v1.2 生僻字词库包（scenario_rare.dict.yaml）

- **词条数**：449（437 词库驱动 + 12 知名扩展 B 补充）。
- **词库驱动选取**：从已部署词库（base/ext/others）中提取出现但**不在《通用规范汉字表》8105**
  的字，按 25 亿字语料字频权重排序取全量（437 字）——即"真实词库里会用到的生僻字"，
  如 齆(weng)、睒(shan)、閦(chu)、槻(gui)、凊(qing)、蠛(mie)、朙(ming) 等。
- **扩展 B 补充**：龘(da)、靐(bing)、齉(nang)、爩(yu)、灪(yu)、麤(cu)、鱻(xian)、飝(fei)、
  龖(da)、龗(ling)、䶮(yan)、爨(cuan) 等网络/名字常用字。
- **拼音来源**：rime-ice 41448 大字表（Unihan kMandarin + 汉典 zdic）。
- **部署机制（2026-08-19 修正）**：词条**内联进 rime_ice.dict.yaml**（主词典内联条目
  才被 librime 编译；实测 import_tables 对这些补充词库不生效，M10-1 原"部署即生效"
  不成立——已一并内联修正）。设置中心「输入 → 专业词场景」下拉新增「生僻字」项
  （options.scenario_dict=rare）。
- **验证**：引擎集成测试（weng→齆、nang→齉、nihao→你好 不回归；运行时探针实测
  449 字中 362 个可直接打出，其余为超高同音竞争码下被淹没、仍可翻页/以词定字）。

## 三、覆盖测算

- 默认拼音可打汉字：8105（通用规范汉字表全量）。
- v1.2 后：8105 + 449 = 8554（另含 rime-ice base/ext 词库中的多字词）。
- 扩展区：U+ 兜底任意码位；41448 大字表按需启用后可按拼音打约 4.1 万字。

## 四、与评估报告的关系

M10-评估报告第四节结论"不建议全量字库，U+ 兜底已满足输入"保持成立；
本词库包按评估建议落地了"常用生僻字 500 表（按使用频率收录）"（实际 449 字，
来源可追溯），把按拼音可打的生僻字覆盖面从 8105 提升到 8554。
